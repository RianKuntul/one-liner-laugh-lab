Entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition on make.fun: a program that writes one short funny line answering a prompt — the excuse a GPS gives after driving you into a lake. The line is a single line of at most 200 characters, written to `entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-lab-out node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
